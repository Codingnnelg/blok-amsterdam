BLOK Amsterdam — Streetwear Webshop

Live site: blok-amsterdam.netlify.app

A dark, urban streetwear landing page and webshop for a fictional Amsterdam-based clothing brand. Built as a portfolio project to demonstrate advanced frontend skills including cart functionality and dynamic product filtering.

📋 Project Overview
TypeFictief portfolio projectNicheStreetwear / e-commerceStackHTML5, CSS3, Vanilla JavaScriptDesignDark urban aesthetic, mobile-first

🛠️ Features

Animated ticker banner
Sticky navbar met cart icon en counter
Hero sectie met product cards
Live countdown timer naar volgende vrijdag drop
Product grid met 12 items (drop + full collection)
Categorie filter (Tees, Hoodies, Bottoms, Accessories)
Werkende winkelwagen sidebar (add, remove, totaalprijs)
New / Low Stock / Sold Out badges
Newsletter signup met success state
Scroll animaties via Intersection Observer
Volledig responsive (mobiel, tablet, desktop)


Note: Checkout functionaliteit is niet geïmplementeerd — dit is een frontend portfolio project. Checkout integratie (Stripe, Mollie) is beschikbaar op aanvraag.


🧰 Tech Stack

HTML5 (semantische structuur)
CSS3 (custom properties, grid, flexbox, CSS animaties)
Vanilla JavaScript (cart state management, filtering, countdown timer)
Google Fonts (Barlow Condensed + Barlow)
